CMANCN 2026 · 神经病学年会日程管理网站

在线网站：https://raven-sera.github.io/neurology-2026-schedule/
GitHub 仓库：https://github.com/raven-sera/neurology-2026-schedule

本地文件
- 当前目录：独立源码、原始 Excel、依赖锁和 GitHub Pages 自动发布配置。
- out：已构建的静态网站成品；请通过 HTTP 服务打开，不要直接双击 HTML。
- 本地网站备份.zip：源码及静态成品备份，不包含 node_modules、Git 历史或浏览器个人资料。
- .verification：制作验收截图和结果记录，不会提交到公开仓库。

本地预览（Node.js 22.13 以上）
在当前目录打开终端，执行：
  npm run preview
浏览器打开：http://localhost:4173/neurology-2026-schedule/
保持终端开启，按 Ctrl+C 停止本地预览。仅监听本机，不向局域网开放。

重新安装和构建
  npm ci
  npm run build:github
  npm run preview
修改源码时可执行 npm run dev，在 http://localhost:3000/ 预览。
GitHub main 分支提交会通过 Actions 自动构建和发布。

更新日程数据
数据唯一依据：本目录的 2026神经病学年会日程.xlsx。
导入脚本需要 Python 和 openpyxl：
  python -m pip install openpyxl
  python scripts/import-schedule.py
  npm run test:calendar
  npm run build:github
只导入“全部日程”工作表，其余日期分表为重复内容，不重复导入。
业务内容生成稳定数字 ID，单纯排序不改变 ID；修改报告的日期、会场、题目等业务身份后会产生新 ID。

内容与功能
- 943 条日程：9 月 11 日 351 条、9 月 12 日 579 条、9 月 13 日 13 条。
- 按题目、报告人、主持、单位、主题和会场检索；支持时间、会场、单位类型、主题及日程类型筛选。
- 收藏、个人日程、时间冲突提示、三日日历、ICS 系统日历文件、日程 PDF 和现场打卡。
- 文本笔记、PPT 图片、录音、个人图书馆、图文 PDF、照片导出及完整 ZIP 备份/恢复。
- 首页直接进入日程看板，不包含三合一入口。
- 克莱茵蓝渐变主题，适配桌面和手机。
- 会场地图按要求暂留空，仅保留空白模块，不猜测位置、坐标或路线。

原表第 328、455、608、609、659、868 行的单项时间超出所属小节范围，忠实保留单项原值，不裁切。
详情保留完整主持、小节时间、小节编号和 Excel 源行号，可下载原始表核对。安排请以大会现场最终通知为准。

隐私与本地数据
笔记、图片、录音、收藏、排期和打卡只保存在当前浏览器，不上传 GitHub，不自动跨设备同步。
大会展示名称已统一为 CMANCN 2026；沿用独立的 neuro2026 内部存储命名、日历事件 UID 和备份格式，确保已有笔记、收藏、排期与旧备份继续可用，不读取或覆盖同域 CSCO 个人资料。
本地与在线网站的浏览器数据彼此独立。更换设备/浏览器前请下载个人图书馆完整 ZIP 备份。
ZIP 备份包含笔记、PPT、录音、标签等资料；个人排期、收藏和打卡不属于资料库 ZIP，请另外导出日程。
PDF 只能阅读，不是可恢复备份；PDF 中不含可播放的音频。
拍摄和录音需浏览器授权，在线 HTTPS 或本机 localhost 环境可用。请遵守会议拍摄和资料使用规定。
